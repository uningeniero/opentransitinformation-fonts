# Google Fonts source and catalogue route

Google Fonts catalogue inclusion is separate from this public font distribution.

This release provides twelve editable UFO sources with contours, components, advances, anchors and text OpenType features. The pinned one-command production uses Fontmake/ufo2ft and a separate ttfautohint executable. Per-font records identify the initial contour conversion from the immutable 1.0.1 fonts and subsequent constructions. Source bindings and required original notices accompany the distribution.

The [production guide](https://googlefonts.github.io/gf-guide/production.html) calls for editable sources and a repeatable open build. The [QA guide](https://googlefonts.github.io/gf-guide/qa.html) identifies Fontspector as the primary tool. This project retains the complete pinned Google Fonts profile, including every reported failure and relevant licence input. Its actual results and residuals are in `qa.md`.

The [onboarding guide](https://googlefonts.github.io/gf-guide/onboarding.html) describes curation for new families and an upgrade route for existing catalogue families. Source conversion, renaming and a completed QA run do not establish eligibility, accepted exceptions or catalogue admission. An upgrade proposal also depends on the applicable upstream source and its maintainers.

The current [submission template](https://github.com/google/fonts/blob/main/.github/ISSUE_TEMPLATE/1_add-font.md) asks for the complete project source, applicable rights and contributor requirements, specimen material and disclosure of AI-tool use. AI coding tools assisted this project's source conversion, build implementation and QA analysis. These tools do not replace the named source authors or licence obligations. No contributor agreement is signed on behalf of an upstream rights holder by this build.

Preserve the original copyright, OFL and Reserved Font Name records with redistribution. The renamed families do not use the inherited Reserved Font Names as their family names. The family OFL files and font metadata identify the current project contributions alongside the retained upstream holders. See the [OFL modification guidance](https://openfontlicense.org/how-to-modify-ofl-fonts/) and [Google Fonts licence guidance](https://googlefonts.github.io/gf-guide/license-file.html) for their respective requirements.
